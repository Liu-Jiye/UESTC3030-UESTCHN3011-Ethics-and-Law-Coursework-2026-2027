## 将题干动词变成写作任务

| 题干动词 | 写完后应有的内容 |
| --- | --- |
| **Classify / distinguish** | 给出分类标准，指出哪项具体事实符合该标准，标出会影响分类的证据缺口。 |
| **Analyse** | 说明因素如何连接到中间事件和后果。例如旧机器人题中，区分报道中的技术指控、管理期限压力和两者之间需要核实的证据。 |
| **Evaluate / justify** | 用同一组标准比较选项，交代谁受到影响、代价是什么，以及什么情况会改变判断。 |
| **Recommend / propose** | 说清执行主体、行动内容、何时执行、如何验证或复核。 |

## 4.1 练习事故机制与控制程序

1. **画一条可查证的事件链。** 先用 *Killer Robot* 练习，逐项记录发生了什么、谁报告了它、是否只是指控、还缺什么验证。把事故现场的直接事件和事前的组织条件放在不同位置，写出中间联系。
2. **用术语解释行为与条件。** 做两栏笔记。第一栏记录执行环节、记忆与判断的证据，第二栏记录程序、培训、监督及信息沟通的证据。用第 12 讲区分记忆遗漏、判断错误和有意偏离。原题没有交代具体漏项时，写出这一不确定性及其影响。
3. **把每项风险对应到控制。** 用旧产品安全题练习填写「危险或失效 → 控制层级 → 责任人 → 验证方式」。从消除、替代和源头工程控制开始，再写作业制度、培训和适用的个人防护。
4. **用第 12 讲复查许可环节。** 对任意设备试验练习填写「许可范围和地点 → 签发或接受与现场核查 → 有效条件和何时暂停 → 作业结束与签闭」。风险评估、人员培训和工程控制应与许可条件相互对应。

自查时逐句标出事实与推断，确认直接原因和潜在条件各自如何影响结果，且每项控制都能对应某个已识别的风险。

## 4.3 练习比较采购选项与验证共享价值

1. **先练同标准比较。** 用 *SDX Alliance* 的商业选择练习比较两种方案。采用 `review.pdf` 第 25 页的问题，分别写谁受益、谁承受成本、短期与长期如何，并记录影响判断的信息缺口。
2. **独立列证据。** 读采购类题目时，把题设给出的成本、市场受益和供应商用工资料分栏。区分成本与最终价格、代表性与实际薪酬、政策与执行效果，避免从一种指标直接推出另一种结论。
3. **把 CSV 写成可检验的机制。** 从 4.3 阅读索引找到原始定义。对所比较的方案分别追踪「经营变化 → 经济价值 → 受益方」与「供应链或市场变化 → 社会价值 → 受益方」，并为两条链各列一种能验证的证据。
4. **用同样的尺度比较拒绝和所提方案。** 对照可负担性、平等改善的可信度、执行成本与证据强度。为所提方案交代责任主体、复核时点与结果未达预期时的决策依据。

自查时看正文是否同时解释了经济价值和社会价值如何产生，是否具体回应了比较对象，以及是否将仍需调查的信息保留为条件。
